# 8주 초과 치료 소견서 작성 보조 앱 — 진행 상황 정리

작성일: 2026-10-20 · 대상: 원장님 · 저장소: https://github.com/tardisdoctordalek-wq/7week

## 1. 앱 개요

자동차보험 경상환자(상해 12~14급 염좌·타박상)가 8주를 넘겨 치료받으려면 진흥원 검토를 받아야 합니다. 이 앱은 비식별화한 진료기록 PDF를 읽고, 정해진 서식(8개 항목)에 맞춰 기록 근거가 붙은 소견서 초안을 만들어 줍니다. 최종 판단과 수정, 서명은 원장님이 합니다.

| 항목 | 내용 |
|---|---|
| 저장소 | https://github.com/tardisdoctordalek-wq/7week |
| 브랜치 | `claude/wizardly-babbage-3sf1oh` (기본 브랜치) |
| 실행 환경 | Windows PC, Python, Streamlit (`실행.bat` 더블클릭) |
| 접속 범위 | 이 PC에서만 (`localhost`) |

## 2. 사용 흐름

1. 진료기록 PDF를 올리고 파일마다 기록 종류(통원·입원·진단서·영상·검사·기타)를 고릅니다. 여러 파일을 한 번에 올릴 수 있습니다.
2. "AI에 전송될 내용 보기"로 내용을 확인하고, 환자를 특정할 정보가 없다는 체크를 합니다.
3. 필요하면 원장님 메모를 적습니다.
4. "초안 작성"을 누릅니다.
5. 결과를 세 탭으로 봅니다: 검토용(근거 표시), 제출용(근거 제거, .txt 저장), 보강·확인 필요 사항.
6. 화면 하단에 입력·출력 토큰 수와 추정 비용(환율 1,400원 가정)이 표시됩니다.

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 다중 PDF + 기록 종류 | 여러 PDF를 올리고 파일별 종류를 지정합니다. 파일 이름에 "입원", "통원", "외래", "진단", "영상", "검사"가 있으면 자동으로 골라 둡니다. AI에는 `=== [종류] 파일명 p.N ===` 형태로 전달됩니다 |
| 스캔 PDF 처리 | 한 쪽의 추출 글자가 30자 미만이면 스캔 PDF로 보고 경고합니다. 그 쪽 내용은 AI에 전달되지 않습니다 |
| 근거 표시·제거 | AI가 문장마다 `[근거: 통원 2026-10-02, p.3]` 형식의 근거를 붙입니다. 제출용 탭에서는 이 표시를 자동으로 지웁니다 |
| 7번 고정 문구 | 7번 항목은 AI 출력과 관계없이 "8주 이후 향후 4주간의 치료가 더 필요할 것으로 사료됩니다"로 바꿔 넣습니다. 7번이 빠져 있으면 8번 앞에 넣습니다 (`prompts.FIXED_ANSWERS`) |
| 모델 선택 | 아래 표 참고 |
| 중복 요청 방지 | AI 작성 중에는 모든 입력과 버튼을 잠급니다. 같은 파일·모델·메모로 다시 누르면 이전 결과를 재사용합니다(추가 비용 없음). 새로 받으려면 "같은 내용으로 다시 작성 (비용 다시 발생)" 버튼을 씁니다 |
| API 키 형식 검사 | 띄어쓰기·한글 등이 섞인 키는 거부합니다. 앞부분이 `sk-ant-`(Claude), `AIza`(Gemini)가 아니면 경고합니다 |
| 키 암호화 저장 | "이 PC에 키 저장 (암호화)"를 누르면 Windows 자격 증명 관리자에 저장됩니다(서비스명 `7week-sogyeonseo`). "저장된 키 삭제" 버튼이 있습니다. 예전의 `api_key.txt`·`gemini_key.txt`가 있으면 자격 증명 관리자로 옮기고 파일을 지웁니다. 암호화 저장이 안 되는 PC에서는 평문으로 저장하지 않습니다 |
| Gemini 무료 키 경고 | Gemini를 고르면, 무료 키 사용 시 입력 자료가 구글 제품 개선에 쓰이고 사람 검토자가 읽을 수 있다는 경고를 표시합니다 |

### 모델과 단가 (100만 토큰당, 유료 기준)

| 모델 | ID | 입력 | 출력 |
|---|---|---|---|
| Claude Haiku 5.5 (기본) | `claude-haiku-5-5` | $0.10 | $0.50 |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | $2.00 | $10.00 |
| Gemini 3.5 Flash-Lite | `gemini-3.5-flash-lite` | $0.30 | $2.50 |
| Gemini 3.8 Flash | `gemini-3.8-flash` | $0.75 | $3.75 |

- Claude Haiku 5.5는 입력이 10만 토큰을 넘으면 $0.50 / $2.50이 적용됩니다.
- Gemini 3.8 Flash는 2026-12-31까지 할인가이고, 2027-01-01부터 $1.50 / $7.50입니다.
- Gemini를 무료 키로 쓰면 실제 청구액은 0원입니다.

## 5. 테스트 현황

**자동 테스트:** 14개 모두 통과 (`python3 -m pytest -q tests`)
- Gemini 응답 처리, 차단 응답, 요청 한도 초과, 잘못된 키 안내
- 비용 계산, 키 형식 검사
- 근거 표시 제거, 출력 나누기, 7번 고정 문구(한 줄·여러 줄·누락·마지막 항목)
- 키 저장·불러오기·삭제, 기존 txt 파일 이전, 암호화 불가 환경 처리

**브라우저 자동 조작으로 확인 (가상 환자 PDF, 가짜 AI 서버, 테스트용 키 저장소 사용)**
- PDF 두 개 업로드와 [입원]/[통원] 구분 전달
- 잘못된 키 입력 시 오류 안내 (Claude·Gemini 모두 실제 서버 응답으로 확인)
- "초안 작성" 6번 연속 클릭 → AI 요청 1번, 같은 내용 재클릭 → 재사용, "다시 작성" → 요청 1번 추가
- 7번이 다른 내용으로 와도 고정 문구로 바뀌어 표시
- 잘못 저장된 Gemini 키 감지, 기존 키 파일 이전, 키 삭제·저장·새로고침 후 불러오기

**확인하지 못한 것**
- 실제 AI 키로 만든 초안의 품질과 실제 건당 비용 (Claude·Gemini 모두)
- 실제 Windows에서 `실행.bat` 동작
- 실제 Windows 자격 증명 관리자에 키가 저장·삭제되는지

## 8. 비용 요약

모두 추정치입니다. 진료기록 약 20쪽을 텍스트로 보내 입력 약 2만 토큰, 출력 약 8천 토큰(AI 사고과정 포함)으로 가정하고, 환율은 1,400원으로 계산했습니다. 실제 금액은 앱 하단에 건마다 표시됩니다.

| 모델 | 100만 토큰당 입력 / 출력 (USD, 유료) | 건당 추정 | 무료 사용 |
|---|---|---|---|
| Claude Haiku 5.5 (기본) | $0.10 / $0.50 (입력이 10만 토큰을 넘으면 $0.50 / $2.50) | 약 10원 | 없음 |
| Claude Sonnet 5.5 | $2 / $10 | 약 170원 | 없음 |
| Gemini 3.5 Flash-Lite | $0.30 / $2.50 | 약 40원 | 있음 (요청 수 제한, 자료가 학습에 쓰일 수 있음) |
| Gemini 3.8 Flash | $0.75 / $3.75 (2026-12-31까지 할인가, 2027년부터 $1.50 / $7.50) | 약 60원 | 있음 (요청 수 제한, 자료가 학습에 쓰일 수 있음) |

- Gemini를 무료 키로 쓰면 실제 청구액은 0원입니다.
- 스캔(사진) PDF는 글자를 추출할 수 없어 AI에 전달되지 않습니다. EMR에서 바로 출력한 PDF를 써야 합니다.
- Claude는 쓴 만큼만 청구되며, Anthropic 콘솔에서 월 사용 한도를 정할 수 있습니다.

인터넷이 안 되거나 GitHub에 접속하지 못하면 업데이트는 건너뛰고 기존 버전으로 실행합니다.

| 파일 | 변경 |
|---|---|
| `update.py` (새로 만듦) | 최신 버전을 확인하고 ZIP을 받아 덮어씀. 파이썬 기본 기능만 사용해 추가 설치가 필요 없음 |
| `version.txt` (자동 생성) | 내 PC에 설치된 버전 번호를 기록 |
| `실행.bat` (수정) | 앱 실행 전에 `update.py`를 먼저 실행 |

업데이트 때 건드리지 않는 것:
- `실행.bat` 자체. 실행 중인 bat 파일을 덮어쓰면 윈도우가 그 파일을 잘못 읽을 수 있어서입니다. `실행.bat`이 바뀔 때만 ZIP을 직접 받으면 됩니다.
- `.venv` 폴더 (이미 설치된 부품)
- 저장한 API 키. 앱 폴더가 아니라 자격 증명 관리자에 있습니다.

처음 한 번은 직접 받아야 합니다. 지금 PC의 `실행.bat`에는 업데이트 기능이 없어서, 이 기능이 들어간 버전은 ZIP으로 직접 받아야 합니다.

주의할 점:
- 저장소에 올라온 수정이 그대로 PC에 들어옵니다. 저장소에 올릴 수 있는 사람은 원장님 계정, 그리고 원장님이 시킨 작업에서의 Claude입니다.
- 올린 수정에 오류가 있으면 그 오류도 함께 들어옵니다.
- 저장소는 현재 공개 상태라 로그인 없이 받을 수 있습니다. 공개된 것은 프로그램 코드뿐이고, 환자 자료나 키는 저장소에 없습니다. 저장소를 비공개로 바꾸면 자동 업데이트는 동작하지 않습니다.
- GitHub은 로그인 없이 확인하는 횟수를 1시간에 60번으로 제한합니다. 하루 몇 번 켜는 정도로는 문제없습니다.

검증:
- 시험용 버전을 올렸다가 되돌리면서 세 경우를 확인합니다. 새 버전 감지 → 받기 → 실행, 최신일 때 아무것도 하지 않음, 인터넷이 끊겼을 때 기존 버전으로 실행.
- 실제 Windows에서는 직접 확인할 수 없어서, 첫 업데이트 때 원장님이 검은 창 내용을 확인해야 합니다.

결정 대기:
- **물어보고 받기 (권장):** 새 버전이 있으면 "업데이트할까요? (Y/N)"를 띄웁니다. 진료 중 급할 때는 건너뛸 수 있습니다.
- **자동으로 받기:** 묻지 않고 바로 받습니다.
