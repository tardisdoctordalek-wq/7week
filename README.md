# 8주 초과 치료 필요성 소견서 작성 보조

자동차보험 경상환자(상해 12~14급 염좌·타박상)가 8주를 넘겨 치료받으려면 사고일로부터 7주 이내에 진단서·진료기록부를 보험사에 제출하고, 자동차손해배상진흥원의 검토를 받아야 합니다. 2026-09-10 이후 사고부터 적용됩니다.

이 앱은 **비식별화한 진료기록 PDF**를 읽고, 아래 서식에 맞춰 **기록에 근거한 소견서 초안**을 만들어 줍니다. 최종 판단과 수정, 서명은 원장님이 하셔야 합니다.

```
상기 환자 TA 후 상기 상병에 대한 보존적 치료 지속하였으나, ... 이하의 내용을 소견합니다.
1) 통증 부위와 강도의 변화 :
2) 관절가동범위와 객관적인 기능 제한 :
3) 보행·운전·수면·업무 등 일상생활의 불편:
4) 신경학적 증상과 진찰 소견 :
5) 기존 치료에 대한 반응 :
6) 증상이 지속되는 의학적 이유 :
7) 필요한 치료의 종류·빈도·예상 기간 :
8) 의학적으로 필요한 검사 및 영상 결과 :
```

## 앱이 하는 일

1. PDF에서 글자를 추출합니다. 입원·통원 기록 등 여러 파일을 한 번에 올리고, 파일마다 종류(통원·입원·진단서·영상·검사·기타)를 지정합니다. 원본 PDF 파일은 PC 밖으로 나가지 않습니다.
2. AI에 실제로 보낼 내용을 화면에 보여줍니다. 환자 인적사항이 없는지 원장님이 확인 체크를 해야 전송됩니다. 개인정보는 PDF를 만들 때 미리 지워 주세요.
3. AI가 작성하는 동안에는 모든 입력이 잠겨, 버튼을 여러 번 눌러도 요청은 한 번만 나갑니다. 같은 내용으로 다시 누르면 이전 결과를 보여주고 추가 비용이 들지 않습니다.
4. 초안의 모든 문장에 `[근거: 날짜, p.쪽]`이 붙습니다. 기록에 없는 내용은 "진료기록상 확인되지 않음"으로 표시합니다.
5. 결과는 세 탭으로 나뉩니다. **검토용**(근거 표시), **제출용**(근거 표시 제거, .txt 저장), **보강·확인 필요 사항**.
6. 건마다 사용한 토큰 수와 비용을 표시합니다.
7. AI는 Claude(Anthropic)와 Gemini(Google AI Studio) 중에서 고를 수 있습니다.

주의할 점이 있습니다.
- 앱은 개인정보를 자동으로 지우지 않습니다. 비식별화한 PDF를 올려 주세요.
- 스캔(사진) PDF는 글자를 추출할 수 없어 해당 쪽은 AI에 전달되지 않습니다. EMR에서 PDF로 바로 출력한 파일을 사용해 주세요.

## 설치 (Windows, 처음 한 번)

### 1) 파이썬 설치
1. https://www.python.org/downloads/ 에서 **Download Python** 버튼을 누릅니다.
2. 설치 첫 화면 아래의 **"Add python.exe to PATH"에 반드시 체크**하고 **Install Now**를 누릅니다.

### 2) 앱 내려받기
1. 이 저장소 GitHub 페이지에서 초록색 **Code** 버튼을 누르고 **Download ZIP**을 선택합니다.
2. 받은 ZIP 파일의 압축을 원하는 폴더에 풉니다.

### 3) API 키 발급

앱 왼쪽에서 Claude(Anthropic)와 Gemini(Google) 중 하나를 골라 쓸 수 있습니다. 쓰려는 쪽의 키만 있으면 됩니다.

**Gemini (Google AI Studio)**
1. https://aistudio.google.com 에 구글 계정으로 로그인합니다.
2. **Get API key**를 누르고 **Create API key**로 키를 만들어 복사합니다.
3. 결제를 등록하지 않으면 무료로 쓸 수 있지만, 분당·하루 요청 수 제한이 있습니다.
4. ⚠️ **무료(결제 미등록) 사용 시**: 구글 약관(Gemini API Additional Terms)에 따르면 입력한 자료와 응답이 구글 제품 개선에 쓰이고, 사람 검토자가 읽을 수 있습니다. 약관은 민감한 개인정보를 넣지 말라고 안내합니다. 결제를 등록하면(유료) 이 사용 대상에서 빠집니다.

**Claude (Anthropic)**
1. https://console.anthropic.com 에 가입하고 로그인합니다.
2. **Billing**에서 결제수단을 등록하고 크레딧을 충전합니다. 최소 금액으로 시작하셔도 됩니다.
3. **Limits**에서 월 사용 한도를 정해두시면 예상보다 많이 나가는 것을 막을 수 있습니다.
4. **API Keys**에서 **Create Key**를 누르고, 나온 키(`sk-ant-...`)를 복사합니다. 키는 이때 한 번만 보이니 따로 보관하세요.

## 실행

1. 압축을 푼 폴더에서 **`실행.bat`을 더블클릭**합니다. 처음 실행할 때는 필요한 프로그램을 설치하느라 몇 분 걸립니다.
2. 브라우저에 앱이 열리면 왼쪽에서 **AI 모델**을 고르고, **API 키** 칸에 해당 키를 붙여넣습니다. **이 PC에 키 저장 (암호화)**를 누르면 다음부터 다시 입력하지 않아도 됩니다.

### API 키 저장·수정·삭제

키는 앱 폴더가 아니라 **Windows 자격 증명 관리자**에 저장됩니다. Windows가 원장님 계정 기준으로 암호화해 보관하므로, 앱 폴더를 복사하거나 OneDrive로 동기화해도 키는 따라가지 않습니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 키 바꾸기 | 키 칸의 내용을 지우고 새 키를 붙여넣은 뒤 **이 PC에 키 저장 (암호화)** → 이전 키를 덮어씁니다 |
| 키 지우기 | 앱의 **저장된 키 삭제** 버튼, 또는 제어판 → 자격 증명 관리자 → Windows 자격 증명 → `7week-sogyeonseo`가 들어간 항목 → 제거 |
| 저장하지 않고 쓰기 | 키를 붙여넣고 저장 버튼을 누르지 않으면 앱을 끌 때 잊어버립니다 |

- 이전 버전에서 만든 `api_key.txt`·`gemini_key.txt`가 있으면, 앱이 켜질 때 자격 증명 관리자로 옮기고 파일은 지웁니다.
- 같은 Windows 계정으로 실행되는 프로그램은 저장된 키를 읽을 수 있습니다(Windows 암호화 방식의 특성). PC를 여러 사람이 같은 계정으로 쓴다면 키를 저장하지 마세요.
3. 끝내려면 검은 창을 닫습니다.

앱은 이 PC에서만 접속할 수 있도록 설정되어 있습니다(`localhost`).

## 비용 (추정)

| 모델 | 100만 토큰당 입력 / 출력 (유료) | 무료 사용 |
|---|---|---|
| Claude Haiku 5.5 | $0.10 / $0.50 (입력이 10만 토큰을 넘으면 $0.50 / $2.50) | 없음 |
| Claude Sonnet 5.5 | $2 / $10 | 없음 |
| Gemini 3.5 Flash-Lite | $0.30 / $2.50 | 있음 (요청 수 제한, 자료가 학습에 쓰일 수 있음) |
| Gemini 3.8 Flash | $0.75 / $3.75 (2026-12-31까지 할인가, 2027년부터 $1.50 / $7.50) | 있음 (요청 수 제한, 자료가 학습에 쓰일 수 있음) |

진료기록 20쪽 정도 1건의 유료 기준 추정치는 Claude Haiku 약 10원, Gemini Flash-Lite 약 40원, Gemini 3.8 Flash 약 60원입니다. 앱 화면 하단에 건마다 실제 토큰 수와 금액이 표시됩니다(환율 1,400원 가정). Gemini를 무료 키로 쓰면 실제 청구액은 0원입니다.

가격은 각 회사의 공식 가격표를 기준으로 했으며 바뀔 수 있습니다. Gemini 모델 이름이 바뀌어 오류가 나면 `llm.py`의 `MODELS`에서 수정합니다.

## 개발자용

```
pip install -r requirements.txt pytest
python -m pytest tests
streamlit run app.py
```

- `app.py`: 화면, PDF 추출
- `llm.py`: Claude·Gemini 호출, 모델·단가 목록
- `keystore.py`: API 키 암호화 저장(Windows 자격 증명 관리자)
- `prompts.py`: 서식과 작성 원칙(AI 지시문)
